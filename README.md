### 🎓 Leçons en Lua/Luau
Le fichier `miniprof.lua` contient :

#### ✅ Variables Colorées
```luau
local maNote = 18.5      -- Notes avec des décimales!
local monAge = 7         -- J'ai 7 ans, comme toi! 🎂
```

#### ✅ Tableaux Magiques (Arrays)
```luau
local couleurs = {"rouge", "bleu", "vert"}
couleurs[4] = "violet"   -- Ajoutons de la couleur! ✨
table.insert(couleurs, "magenta")  -- Plus encore! 🌈
```

#### ✅ Fonctions Drôles
```luau
function saluerNom(personne)
    return "Salut " .. personne .. "! Bienvenue! 🌸"
end
print(saluerNom("Robi"))  -- "Salut Robi!"
```

#### ✅ Loops Super Sympas
```luau
for i = 1, 5 do
    print(i .. ". " .. string.rep("⭐", i))
end
-- 🌟✨💫🎉 (super mignon!)
```

#### ✅ Tables Dictionnaires (Maps)
```luau
local monCarnet = {
    math = 18.5,
    francais = 16.0,
    science = 20.0
}
-- Accès par clé: monCarnet.math
```

#### ✅ Conditions Mignonnes
```luau
if maNote >= 18 then
    print("Excellent! 🏆")
elseif maNote >= 15 then
    print("Pas mal! 💪")
else
    print("Continue les efforts! 🌈")
end
```
